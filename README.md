# machine_vision_face_mask_detection

# 🎥 سیستم مانیتورینگ ویدئویی چندمنبعی

یک برنامه دسکتاپ با استفاده از **Python** و **Tkinter** برای نمایش همزمان ۴ منبع ویدئویی مختلف، طراحی شده برای نظارت و تشخیص ماسک.

## ✨ قابلیت‌ها

- **نمایش همزمان ۴ منبع ویدئویی** در یک پنجره با چیدمان ۲×۲
- **پشتیبانی از منابع متنوع**:
  - 📡 استریم آنلاین (URL)
  - 📱 دوربین گوشی از طریق USB
  - 💻 وبکم داخلی سیستم
  - 🎥 فایل ویدئویی محلی (MP4، AVI، MOV، MKV)
- **مدیریت خودکار اتصال** و تلاش مجدد در صورت قطعی
- **ریسایز هوشمند** با حفظ نسبت تصویر
- **رابط کاربری فارسی** با پشتیبانی از فونت‌های سفارشی
- **سیستم ورود ساده** برای امنیت اولیه
